# Skilful Skill

[中文](README_ZH.md) | English

Skilful Skill is a project for organizing, maintaining, and distributing multiple AI skills. It is designed for AI agents, developers, and automation workflows, with the goal of making skills easier to discover, understand, reuse, and extend.

## Goals

- Collect skills for different use cases, such as development assistance, code review, debugging, document handling, data analysis, and automation tasks.
- Describe each skill with a clear and stable structure, including purpose, trigger scenarios, inputs, outputs, and cautions.
- Provide AI-friendly documentation so agents can quickly decide when to use a skill and how to execute it safely.
- Keep the content concise and maintainable while leaving room for future expansion.

## AI-Friendly Conventions

- Each skill should explain when it applies, what its limits are, and what outcome is expected.
- Examples should be concrete rather than purely abstract.
- File names and directory structure should stay stable to make agent retrieval easier.
- Important behavior should be explicit to reduce hidden assumptions.

## Current Status

This is the initial version of the project. Skill directories, templates, examples, and contribution guidelines will be added over time.
